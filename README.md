# OAReactDiff-Shimmer: 物理增强的 MECI 生成推演

本项目基于扩散模型与机器学习力场（MACE），专注于寻找化学反应中的 **圆锥交叉点（Minimum Energy Conical Intersection, MECI）**。

通过结合 **ReactOT** 的生成能力与 **X-MACE** 的物理势能面约束，我们实现了一种能够从反应物（Reactant）自动推演至物理精确交点的动力学路径。

---

## 核心亮点：轨迹回溯评估 (Trajectory Hunting)

在扩散推演过程中，模型往往在几何对齐（RMSD）与物理收敛（Gap）之间存在权衡。我们实现了 `eval_singlemol.py`，其核心逻辑在于：

* **多帧采样**：记录 ODE 推演路径上的 50 帧快照。
* **物理筛选**：不盲目选择最后一帧，而是自动回溯整条轨迹，寻找 **S1-S0 能隙（Gap）** 最小的物理最优瞬间。

---

## 🚀 成果展示：典型案例 Aa91156 (21 Atoms)

以下是使用本框架对分子 **Aa91156** 进行 MECI 推演的实测数据。结果显示，模型成功绕过了势能面上的高能脊，捕捉到了极低能隙的物理构型。

### 1. 物理性能对比

| 阶段 | S0 能量 (eV) | S1 能量 (eV) | **能隙 (Gap, eV)** |
| --- | --- | --- | --- |
| **原始反应物** | -10528.8929 | -10528.6497 | 0.2431 |
| **生成最优帧 (F43)** | -10528.6052 | -10528.5763 | **0.0289** |

> **评估结论**：能隙从 **0.243 eV** 锐减至 **0.0289 eV**，降幅高达 **88%**，成功命中了物理交点区域。

### 2. 演化轨迹观测

在 50 帧的推演中，能隙表现出**非单调优化**的特征：

* **初始阶段**：由于轨迹初期的位移，能隙曾一度反弹。
* **后期阶段 (Frame 43)**：物理引导力与几何拉力达到平衡，能隙降至全球最低。
* **收敛阶段 (Frame 49)**：末期为了绝对对齐目标坐标，能隙轻微反弹至 0.05 eV。

这有力地证明了 **“最优帧筛选”** 逻辑在处理复杂势能面时的优越性。

## 🛠️ 快速开始

### 单分子测试与评估

你可以通过以下命令对指定分子进行全轨迹推演与最优帧筛选：

```bash
python eval_singlemol.py

```

该脚本会自动：

1. 加载最新的 `last-v1.ckpt` 微调权重。
2. 启动 500 步 NFE 的 ODE 采样。
3. 自动筛选并保存 `comparison_result.xyz` 对比文件。
